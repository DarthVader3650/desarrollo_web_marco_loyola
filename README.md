# desarrollo_web_marco_loyola

Muy buenas gente, acá econtrarán mi página web para el curso desarrollo de aplicaciones web. Quería comentar algunos puntos de mi tarea 1:

- Traté de que toda la página tenga una interfaz de un mismo tono, en este caso el color azul. Así se siente que uno navega por la misma página.
- Las fotos elegidas para los ejemplos son (en su mayoría) memes, con el objetivo de entretener. Si es necesario cambiarlos en un futuro no hay problema.
- Si pueden entregarme feedback sobre el diseño de la página (posición de las fotos, tamaños, más elementos llamativos, etc) estaría encantado, ya que quiero que sea algo que guste a las personas, además de que quede bonita.

Eso, ojalá les guste la página.
